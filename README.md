Developed an interactive Power BI dashboard to analyze 20,000+ road accident records across multiple Indian states.
Designed KPI cards to monitor Total Accidents, Major Accidents, Minor Accidents, Total Casualties, and Average Risk Score.
Built trend analysis visualizations to identify monthly accident patterns and accident severity trends across multiple years.
Implemented state-wise geospatial analysis using map visuals to identify accident-prone regions.
Created cause-wise accident distribution analysis to understand key contributing factors such as overspeeding, poor road conditions, weather, distraction, and drunk driving.
Utilized DAX measures and calculated metrics to generate actionable business insights.
Enabled dynamic report exploration through interactive filters and slicers for state-level analysis.
