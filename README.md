This dashboard provides insights into Indian road accident trends by analyzing accident counts, casualty numbers, severity distribution, accident causes, and geographical accident concentration across states





**Dashboard Insights**


• 20,000 total accidents analyzed.
• 35K total casualties recorded.
• Minor accidents represent the highest share of accidents.
• Overspeeding, weather conditions, and poor road infrastructure remain key contributors.
• State-wise analysis highlights accident concentration across major Indian states.
